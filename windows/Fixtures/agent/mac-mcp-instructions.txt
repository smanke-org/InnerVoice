Tools that drive InnerVoice, the audiobook narrator's app on this Mac: see the open projects, chapters, lines and cast, assign lines to characters, change a line's kind, rename, recolor and merge characters, run Tag Speakers and Build Summaries with the on-device model, set pronunciations, choose the model, and export narrator scripts, the tagged manuscript, the cast list or the pronunciation guide. Changes show in the project window at once and Edit › Undo works on them. Most tools take project (a name or path; default the frontmost window). Line ids come from lines_list. Destructive tools only report what they would change unless yes is true (the CLI's --yes). Error code no_model means no model is ready: model_list, then model_select.

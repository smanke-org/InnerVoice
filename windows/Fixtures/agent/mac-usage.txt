=== status
Show the version, the open projects (the frontmost first), the model and whether it is ready, and what the AI is doing in each project.

  innervoice status

Example: innervoice status --json
=== open
Show a page in a project's window: manuscript, cast, voices, index, pronunciations, record, retakes, review or revisions. With --character, opens that character on the Cast page.

  innervoice open [<page>] [--character <string>] [--project <string>]

  page          manuscript, cast, voices, index, pronunciations, record, retakes, review or revisions (default manuscript)
  --character   open this character's page in Cast (a name, alias or id)
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice open cast --character Mara --json
=== projects list
List the open projects, the frontmost first. Returns `projects` (id, name, title, author, path, front, edited, chapters, lines, linesNeedingYou, characters, tagging).

  innervoice projects list

Example: innervoice projects list --json
=== projects open
Open a saved project (.innervoice) in its own window, as File › Open… does. If it is open already, returns it.

  innervoice projects open <path>

  path          the .innervoice project

Example: innervoice projects open ~/Documents/Harbor.innervoice --json
=== projects new
Start a project from a manuscript (Word, PDF, RTF, text, Markdown, OpenDocument, Pages, EPUB or HTML), as File › New from Manuscript… does: finds every line and runs the plain rules. The window opens untitled; the person saves it with File › Save.

  innervoice projects new --manuscript <path>

  --manuscript  the manuscript file

Example: innervoice projects new --manuscript ~/Documents/Harbor.docx --json
=== projects save
Save a project, as File › Save does. With --as, save it to a new .innervoice file, as File › Save As… does (needed the first time an untitled project is saved).

  innervoice projects save [--as <path>] [--project <string>]

  --as          save to this .innervoice file instead
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice projects save --as ~/Documents/Harbor.innervoice --json
=== chapters list
List the chapters in book order. Returns `chapters` (number, title, paragraphs, words, lines, linesNeedingYou).

  innervoice chapters list [--project <string>]

  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice chapters list --json
=== lines list
List lines in book order. Returns `lines` (id, ref like "Ch 3 ¶12", speaker, kind, source, confidence, needsYou, text, tone, toneSource, toneConfidence, toneNeedsYou), `total` and `nextOffset` when there are more.

  innervoice lines list [--chapter <integer>] [--speaker <string>] [--needs-you] [--search <string>] [--limit <integer>] [--offset <integer>] [--project <string>]

  --chapter     only this chapter (from 1, see `innervoice chapters list`)
  --speaker     only this character's lines (a name, alias or id), or "none" for Who's Speaking?
  --needs-you   only red lines: Who's Speaking? and Unsure
  --search      only lines whose text contains this
  --limit       at most this many (default 50)
  --offset      skip this many, for the next page
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice lines list --chapter 2 --needs-you --json
=== lines assign
Give lines to a character, as Assign To does in the manuscript (one Edit › Undo step). Or --clear them back to Who's Speaking?; --clear only reports what it would change until --yes.

  innervoice lines assign <ids>... [--to <string>] [--new] [--clear] [--project <string>] [--yes]

  ids           line ids from `innervoice lines list`
  --to          the character (a name, alias or id)
  --new         make the character named by --to if there is none yet
  --clear       make the lines Who's Speaking? again
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)
  --yes         with --clear: do it. Assigning to a character needs no --yes

Example: innervoice lines assign 3f2a9c1e 7b0d44e2 --to Mara --json
=== lines kind
Change what kind of line these are: spoken, thought or written (one Edit › Undo step).

  innervoice lines kind <ids>... [--kind <string>] [--project <string>]

  ids           line ids from `innervoice lines list`
  --kind        spoken, thought or written. May also come last: `lines kind 3f2a9c1e thought`
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice lines kind 3f2a9c1e thought --json
=== lines tone
Set how lines are said, as Tone does in the line's menu (one Edit › Undo step): neutral, excited, confused, sad, angry, whispered, scared, tender or sarcastic. Tag Speakers never changes a tone set this way.

  innervoice lines tone <ids>... [--tone <string>] [--project <string>]

  ids           line ids from `innervoice lines list`
  --tone        the tone. May also come last: `lines tone 3f2a9c1e angry`
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice lines tone 3f2a9c1e angry --json
=== lines reveal
Show a line in the manuscript, selected, as clicking it in the Index does.

  innervoice lines reveal <id> [--project <string>]

  id            the line's id (see `innervoice lines list`)
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice lines reveal 3f2a9c1e --json
=== characters list
List the cast, most lines first. Returns `characters` (id, name, aliases, color, lines, words, firstLine, chapters, facts, narrator, showInIndex, voice).

  innervoice characters list [--project <string>]

  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice characters list --json
=== characters show
Show one character: summary facts with their sources ("Ch 2 ¶4") and Revealed Late flags, notes, voice notes, narrator, and line and word counts.

  innervoice characters show <name> [--project <string>]

  name          the character: a name, alias or id
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice characters show Mara --json
=== characters merge
Make two characters one, as Merge does in Cast: every line and fact of FROM moves to TO, and FROM's names become TO's aliases. Only reports what it would change until --yes (Edit › Undo can take it back).

  innervoice characters merge <from> --into <string> [--project <string>] [--yes]

  from          the character to merge away (a name, alias or id)
  --into        the character to keep
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)
  --yes         do it. Without --yes it only shows what it would change

Example: innervoice characters merge Mara --into "Mara Quinn" --yes --json
=== characters rename
Rename a character, as editing the name on its Cast page does. To make two characters one, use `characters merge`.

  innervoice characters rename <name> --to <string> [--project <string>]

  name          the character: a name, alias or id
  --to          the new name
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice characters rename Tom --to "Tom Hale" --json
=== characters color
Change a character's color in the manuscript. Takes auto (the default: blues and greens for men, pinks and purples for women, warm colors when the book doesn't say), #RRGGBB or a palette name (Blue, Pink, Amber…). Reddish colors are refused: red means Who's Speaking?

  innervoice characters color <name> <color> [--project <string>]

  name          the character: a name, alias or id
  color         auto, #RRGGBB, or a palette name: Blue, Emerald, Indigo, Teal, Sky, Green, Slate, Cyan, Fuchsia, Violet, Lavender, Orchid, Pink, Purple, Lilac, Blush, Amber, Lime, Orange, Brown, Gold, Olive
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice characters color Mara "#0EA5E9" --json
=== casting style
Show or change the book's Casting Style: one-voice (One Voice, or Just Me when narrating), shared (Narrator + Two Voices, or Three Narrators) or full-cast. Changing it keeps every voice and narrator. Returns `castingStyle` and who reads each character (`readers`).

  innervoice casting style [<style>] [--project <string>]

  style         one-voice, shared or full-cast (leave out to show the current one)
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice casting style shared --json
=== characters gender
Set a character's gender: male, female, other, or auto (what the book says). Casting Style sorts by it; colors and casting follow it.

  innervoice characters gender <name> <gender> [--project <string>]

  name          the character: a name, alias or id
  gender        male, female, other or auto
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice characters gender Quinn other --json
=== characters main
Mark a character as a main character (yes), not main (no), or neither (auto). In Full Cast, main characters always have a voice of their own.

  innervoice characters main <name> <main> [--project <string>]

  name          the character: a name, alias or id
  main          yes, no or auto
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice characters main Mara yes --json
=== characters read-by
Choose who reads a character under the Casting Style: narrator, men, women, other, own (a voice or narrator of their own), or auto (the style decides).

  innervoice characters read-by <name> <role> [--project <string>]

  name          the character: a name, alias or id
  role          narrator, men, women, other, own or auto
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice characters read-by Kade own --json
=== characters shade
Set how the narrator shades a character: pitch (-4 to 4 semitones, lower to higher), pace (-2 to 2) and a few words, or --auto to go back to the shade worked out from gender, age and the voice brief.

  innervoice characters shade <name> [--pitch <integer>] [--pace <integer>] [--words <string>] [--auto] [--project <string>]

  name          the character: a name, alias or id
  --pitch       -4 (much lower) to 4 (much higher)
  --pace        -2 (slower) to 2 (quicker)
  --words       texture for the cue: gravelly, clipped…
  --auto        use the automatic shade again
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice characters shade Tom --pitch -2 --pace -1 --words gravelly --json
=== tag start
Start Tag Speakers: the on-device model decides who speaks every line the narrator and the rules haven't settled. Runs in the background; follow it with `innervoice tag status`. Lines the narrator assigned are never changed.

  innervoice tag start [--chapter <integer>] [--project <string>]

  --chapter     only this chapter (from 1)
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice tag start --json
=== tag stop
Stop Tag Speakers or Build Summaries. What the AI has done so far is kept.

  innervoice tag stop [--project <string>]

  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice tag stop --json
=== tag status

  --character   only this character (a name, alias or id)

  innervoice pronunciations list [--search <string>] [--all] [--limit <integer>] [--offset <integer>] [--project <string>]

  --search      only terms or sayings containing this
  --all         include terms dismissed as needing no entry
  --limit       at most this many (default 50)
  --offset      skip this many, for the next page
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice pronunciations list --json
=== pronunciations set
Say how to pronounce a term, as typing in the Pronunciations list does. Adds the term when it isn't there yet.

  innervoice pronunciations set <term> [--say-it-as <string>] [--notes <string>] [--confirmed] [--project <string>]

  term          the term (or its id)
  --say-it-as   how to say it, like SHEV-on
  --notes       your notes
  --confirmed   checked with the author or rights holder (true or false)
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice pronunciations set Kerensa --say-it-as "keh-REN-sah" --json
=== export
Export a Narrator Script, the tagged manuscript, the cast list or the pronunciation guide, as File › Export… does, to a file.

  innervoice export --kind <string> [--format <string>] --out <path> [--narrator <string>] [--no-cues] [--no-summaries] [--replace] [--project <string>]

  --kind        narrator-script, manuscript, cast or pronunciations
  --format      pdf (default) or word; cast and pronunciations also csv
  --out         the file to write (.pdf, .docx or .csv is added when missing)
  --narrator    narrator-script only: this narrator's characters (default every character)
  --no-cues     narrator-script only: leave out the cue line before each line
  --no-summariesnarrator-script only: leave out the character summaries
  --replace     replace the file if it exists
  --project     the project: its name, path or id from `innervoice projects list` (default: the frontmost)

Example: innervoice export --kind narrator-script --narrator Ana --format pdf --out ~/Desktop/Ana.pdf --json
=== model list
List the models InnerVoice can use, with advice for this Mac's memory. Returns `models` (id, name, size, quality and speed 1 to 5, fit, note, downloaded, selected, recommended, download) and `apple` (Apple's on-device model).

  innervoice model list

Example: innervoice model list --json
=== model select
Choose the model Tag Speakers and Build Summaries use, as Use This Model does: a downloaded model's id, "apple" for Apple's on-device model, or the path to your own .gguf file.

  innervoice model select <id>

  id            a model id from `innervoice model list`, apple, or a .gguf path

Example: innervoice model select gemma-4-e4b --json
=== model download
Download a model from the list (2.5 to 19 GB from Hugging Face; the only network use besides updates). Only reports the size until --yes. Follow it with `innervoice model list`; when it finishes it becomes the model if none was ready.

  innervoice model download <id> [--yes]

  id            a model id from `innervoice model list`
  --yes         start the download. Without --yes it only shows the size and the fit for this Mac

Example: innervoice model download gemma-4-e4b --yes --json
